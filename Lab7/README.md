# 💾 Bài tập CRUD Cơ bản với Firebase
=================================

Ứng dụng này minh họa các thao tác cốt lõi trong việc quản lý dữ liệu trực tuyến, bao gồm: Thêm mới (Create), Đọc/Hiển thị (Read), Cập nhật (Update) và Xóa (Delete). Toàn bộ dữ liệu của ứng dụng được lưu trữ và đồng bộ hóa trên đám mây thông qua dịch vụ cơ sở dữ liệu của Firebase (như Cloud Firestore).

### 📚 **Kiến thức yêu cầu**
--------------
* Nắm vững cú pháp của ngôn ngữ **Kotlin** và cách làm việc với xử lý bất đồng bộ (Coroutines).
* Biết cách cấu hình và tích hợp dự án **Firebase** vào ứng dụng Android.
* Biết cách sử dụng SDK của Firebase để thực hiện các truy vấn đọc, ghi, cập nhật và xóa dữ liệu trên database.
* Biết cách xây dựng giao diện bằng **Jetpack Compose** và quản lý trạng thái (State) để cập nhật giao diện theo thời gian thực khi dữ liệu từ Firebase thay đổi.

### 🚀 **Hướng dẫn cài đặt và chạy ứng dụng**
---------------
1. Cài đặt Android Studio trên máy (nếu chưa có).
2. Tải mã nguồn (source code) của bài tập về.
3. **Lưu ý quan trọng:** Đảm bảo dự án đã có file `google-services.json` để kết nối chính xác với Firebase.
4. Mở Android Studio và Import project này vào.
5. Chọn **Build** và **Run** để chạy thử ứng dụng.
