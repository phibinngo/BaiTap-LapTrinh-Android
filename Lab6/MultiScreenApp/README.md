# 📱 Ứng dụng MultiScreen
=================================

Ứng dụng này minh họa cơ bản cách xây dựng một ứng dụng Android có nhiều màn hình. Trọng tâm của bài tập là cách thiết lập luồng điều hướng (navigation) để chuyển đổi qua lại giữa các màn hình khác nhau trong ứng dụng.

### 📚 **Kiến thức yêu cầu**
--------------
* Nắm được cú pháp của ngôn ngữ **Kotlin**.
* Biết cách tạo giao diện cơ bản bằng các hàm Composable (**Jetpack Compose**).
* Biết cách sử dụng thư viện **Navigation Compose** để thiết lập route và điều hướng giữa các màn hình.

### 🚀 **Hướng dẫn cài đặt và chạy ứng dụng**
---------------
1. Cài đặt Android Studio trên máy (nếu chưa có).
2. Tải mã nguồn (source code) của bài tập về.
3. Mở Android Studio và Import project này vào.
4. Chọn **Build** và **Run** để chạy thử ứng dụng.
